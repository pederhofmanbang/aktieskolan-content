# IDEAS

Tankegods och oformella idéer för detta projekt. Senaste först. Uppdateras BARA på `main`-branchen.

När en idé mognar till något konkret, bryt ut den till en GitHub Issue med:
```
gh issue create --title "Kort titel" --body "Detalj" --label idea
```
och stryk den från denna fil.
